# MeloUnion 设计规范

本目录将 AI 概念稿收敛为可开发、可复审的 UI 规格。概念图用于确认视觉方向；本目录中的尺寸、状态、组件责任和响应式规则才是实现时的准绳。

## 设计目标

- **一级导航聚焦**：桌面端侧边栏只保留“喜欢 / 歌单 / 推荐”，下载与设置作为工具入口。
- **Provider 在内容区切换**：不在侧边栏重复列出网易云、QQ 音乐或未来 Provider；按页面在内容区顶部以 Tabs 组织。
- **播放控制始终可达**：桌面端底部播放条全宽贯通；移动端使用迷你播放器并可进入全屏播放器。
- **来源和能力透明**：来源标签、收藏状态、只读状态、登录失效与不可播放原因必须明确可见。
- **跨端同一语言**：Windows 与 Android 使用同一组颜色、间距、圆角、组件语义与 Provider Tab 逻辑；布局按平台适配，而不是机械缩放。

## 视觉方向

当前批准方向为**轻量、清晰、音乐库导向的浅色界面**：白色/浅灰画布、青绿色主色、来源标签的弱语义色、圆角卡片与克制阴影。深色主题可以在后续作为完整 Theme Variant 支持，但不应成为当前页面还原的默认视觉基线。

## 交付边界

本目录不替代 Figma 源文件，也不保存账号、平台图标授权素材或真实歌曲封面。开发阶段可使用脱敏 Mock 数据、渐变封面和通用图形占位；接入真实 Provider 后再由远端元数据提供封面、歌词与来源图标。
