# 01 · Foundations：视觉 Token 与响应式尺寸

> 所有数值先以本文件为准。Flutter 实现应通过统一 Token / Theme 使用，不在页面中散落颜色和间距常量。

## 2. 字体

优先使用系统中文字体回退链：Windows 为 `Microsoft YaHei UI` / `Microsoft YaHei`，Android 为 `Noto Sans CJK SC` / 系统 sans；后续可统一打包开源字体。

| 样式 | 字号 / 行高 | 字重 | 用途 |
|---|---:|---:|---|
| `display` | 32 / 40 | 600 | 空态或特殊大标题；普通内容区默认不用 |
| `sectionTitle` | 20 / 28 | 600 | 卡片标题、弹层标题 |
| `pageLabel` | 16 / 24 | 600 | App Bar、小标题 |
| `body` | 14 / 20 | 400 | 歌曲行、正文 |
| `bodyStrong` | 14 / 20 | 600 | 歌曲名、重要值 |
| `caption` | 12 / 18 | 400 | 歌手、来源说明、标签 |
| `micro` | 11 / 16 | 500 | 紧凑来源标签、计数 |

数字时间、时长、播放进度建议使用等宽数字特性或视觉接近的字体变体，避免列表跳动。

## 3. 间距

采用 4 px 基础栅格：

```text
4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64
```

常用规则：

- 页面容器内边距：桌面 24，移动 16。
- 卡片内边距：16；紧凑卡片 12。
- 表格 / 列表行高：桌面 52–56；移动 64–72。
- Provider Tabs 与内容间距：16。
- 左侧导航项目间距：8；导航组之间：20–24。

## 4. 圆角与阴影

| Token | 值 | 使用位置 |
|---|---:|---|
| `radius.sm` | 8 | 标签、输入框、小按钮 |
| `radius.md` | 12 | 列表选中底、歌单卡 |
| `radius.lg` | 16 | 播放面板、弹层 |
| `radius.xl` | 24 | 全屏播放器封面容器、移动 Sheet |
| `radius.pill` | 999 | 圆形播放按钮、胶囊状态 |

| 阴影 | 值 | 使用位置 |
|---|---|---|
| `shadow.subtle` | `0 1px 2px rgba(16,24,40,.06)` | 普通卡片 |
| `shadow.medium` | `0 4px 12px rgba(16,24,40,.08)` | 悬浮播放器、下拉菜单 |
| `shadow.strong` | `0 8px 24px rgba(16,24,40,.12)` | 全屏 Sheet、重要浮层 |

默认优先使用边框和背景层级；阴影只用于真实悬浮关系。

### Mobile

| 元素 | 尺寸 |
|---|---:|
| App Bar | 56 px |

| Mini Player | 64 px |
| Bottom Navigation | 72 px（含安全区） |
| 全屏封面 | 宽度 - 48 px，最大 360 px |

## 6. 动效

- Tab 切换：150–200 ms 的淡入 / 指示线位移。
- 收藏心形：120 ms scale + color transition；失败时回滚并显示 SnackBar。
- Mini Player → 全屏播放器：220–280 ms 共享元素或淡入上移。
- 列表骨架 → 数据：150 ms crossfade。

动画不得阻碍播放、收藏、下载或页面返回操作。
