# 05 · 交互、加载与异常状态

视觉稿只表达理想数据状态；本文件规定真实产品必须实现的状态，避免 UI 在登录失效、Provider 故障或资源过期时误导用户。

## 1. 页面状态矩阵

| 页面 | 初次加载 | 有数据 | 空数据 | 局部失败 | 全量失败 |
|---|---|---|---|---|---|
| 全部喜欢 | 歌曲行 Skeleton | 合并歌曲列表 | “还没有喜欢的歌曲” | 显示失败来源 Banner，保留其他来源 | Error State + 重试 |
| Provider 喜欢 | 行 Skeleton | 单来源歌曲 | “此来源暂无喜欢” | 缓存 + 刷新失败时间 | 登录/连接引导 |
| 歌单 | 卡片 Skeleton | 卡片/列表 | “新建第一个歌单” | Provider Tab 内错误 | Error State |
| 推荐 | 模块 Skeleton | 推荐模块 | “暂未提供推荐” | 当前 Provider 局部错误 | 切换可用 Provider |
| 下载 | 任务占位行 | 任务列表 | “暂无下载任务” | 单任务错误 | 存储/权限引导 |

## 2. 登录与 Provider 状态

### 未登录

- Provider Tab 可显示，但内容区使用空态 / Banner：`登录后查看网易云喜欢的音乐`。
- 主操作为“登录”；次操作为“了解支持能力”。
- 不要显示 0 首歌曲来假装同步成功。

### 登录失效

- 保留最近一次不含秘密的缓存元数据，并显示：`登录已失效 · 数据更新于 2 小时前`。
- 顶部 Banner 提供“重新登录”。
- 收藏、播放、下载等依赖会话的按钮禁用并给出原因。

### Provider 暂不可用

- 仅影响该 Provider Tab 和它在“全部喜欢”中的刷新状态。
- “全部喜欢”继续展示其他来源，状态栏列出：`QQ音乐未刷新`。
- 不能因为单一 Provider 故障让全页进入全屏错误。

## 3. 收藏状态机

```text
未喜欢 ─点击→ 提交中 ─成功→ 已喜欢
  ↑                 │失败
  └──────回滚───────┘
```

- 乐观更新前写入 Outbox。
- 提交中禁用重复点击或显示细小进度。
- 若条目有多个来源，先让用户选择来源，不执行隐式批量取消。
- 失败提示包含原因：网络、登录失效、只读 Provider、会员/版权限制、协议变化。

## 4. 播放状态

| 状态 | UI |
|---|---|
| idle | 不显示 Mini Player；桌面播放器显示空队列引导 |
| buffering | 封面/按钮保留，显示小型缓冲指示，不遮挡控制 |
| playing | 播放按钮为暂停；队列中当前行高亮 |
| paused | 播放按钮为播放；保持上下文 |
| ended | 自动推进或按循环策略处理 |
| urlExpired | 显示“正在刷新播放资源”；重试一次后报告失败 |
| unavailable | 标记当前来源不可播，可提供切换可用来源（后续能力） |

## 5. 下载状态

```text
queued → resolving → downloading → paused → completed
                            └────→ failed → retrying
```

- 显示来源、质量、进度、剩余时间、输出位置。
- 恢复下载重新请求临时票据，不复用旧 URL。
- 无下载能力的来源显示禁用说明，而非隐藏下载功能导致用户猜测。
- Android 存储授权失败要提供“打开设置”或重新选择目录。

## 6. 空态文案建议

| 场景 | 标题 | 行动 |
|---|---|---|
| 全部喜欢为空 | 还没有聚合到喜欢的歌曲 | 去登录音乐来源 / 去推荐页看看 |
| 本地歌单为空 | 创建第一个本地歌单 | 新建歌单 |
| Provider 未登录 | 登录后查看此来源内容 | 登录 |
| 推荐不可用 | 此来源暂未提供推荐 | 切换来源 |
| 队列为空 | 还没有待播放歌曲 | 去喜欢或推荐页播放一首 |
| 下载为空 | 下载的歌曲会出现在这里 | 去歌曲菜单下载 |

## 7. 确认与撤销

- 删除本地歌单：确认对话框，默认焦点放在取消。
- 从本地歌单移除歌曲：SnackBar 提供“撤销”。
- 取消远端喜欢：单来源可直接执行并允许短暂撤销（若 Provider 写回成功且支持）；多来源必须先选择来源。
- 登出 Provider：提醒该 Provider 的会话将清除，但本地歌单中保存的歌曲引用与缓存元数据会保留。

## 8. 键盘与无障碍反馈

- 焦点态使用 2 px `primary.500` 外描边，不只依赖阴影。
- 异步收藏、下载、播放状态改变需提供语义公告。
- 错误 Banner 不能只显示图标；必须有文本和操作按钮。
