# 02 · 可复用组件规格

组件必须以 Provider 无关、状态可表达和跨端可复用为目标。UI 不应根据 `provider == netease` 或 `provider == qqMusic` 写分支，而应读取 descriptor 与 capability。

## A. 一级侧栏 `DesktopPrimarySidebar`

**用途**：Windows ≥ 960 px 的全局任务导航。

| 属性 | 规格 |
|---|---|
| 项目 | 喜欢、歌单、推荐、下载、设置 |
| 选中态 | `primary.50` 背景 + `primary.700` 图标/文字 |
| 非选中 | `textPrimary` 图标/文字，Hover 使用 `surfaceMuted` |
| 禁止 | 在侧栏中重复列出网易云、QQ音乐或未来 Provider |
| 工具项 | 下载、设置与主要三项以分割线 / 间距隔开 |

## B. Provider Tabs `ProviderTabs`

**用途**：切换当前页面的内容来源。

```dart
class ProviderTabItem {
  final String id;             // all / local / providerId
  final String label;
  final bool enabled;
  final bool requiresLogin;
  final String? disabledReason;
}
```

| 页面 | Tab 首项 | 后续项 |
|---|---|---|
| 喜欢 | 全部喜欢 | 可读取收藏的 Provider |
| 歌单 | 本地歌单 | 可读取用户歌单的 Provider |
| 推荐 | 第一个可推荐 Provider | 其余可推荐 Provider |

- 桌面：固定高度 44，超出时使用“更多平台”菜单。
- 移动：横向滚动，保留当前 Tab 可见。
- 未登录 Provider：可显示 Tab，但点击后进入登录引导，不假装已有数据。
- 无能力 Provider：默认不显示；设置页可查看其能力说明。

## C. 歌曲行 `SongRow`

| 字段 | 桌面 | 移动 |
|---|---|---|
| 序号 / 播放状态 | 左侧 32 px | 可选，推荐场景可省略 |
| 封面 | 32–40 px | 44–48 px |
| 主信息 | 歌名、歌手、专辑 | 歌名、歌手 |
| 来源 | 一至多个 `SourceTag` | 一至多个 `SourceTag`，必要时折叠 |
| 时长 | 独立列 | 右侧弱文本 |
| 收藏 | `FavoriteButton` | `FavoriteButton` |
| 菜单 | 溢出菜单 | 溢出菜单 |

交互：单击行播放；双击 / 回车立即播放并替换当前上下文；右键 / 长按打开菜单；心形操作不得触发行播放。

## D. 歌单卡 `PlaylistCard`

- 1:1 封面，圆角 12。
- 显示名称、歌曲数、来源标签和溢出菜单。
- 本地歌单可显示“混合”标签；远端歌单显示其 Provider 标签。
- Hover（桌面）显示播放覆盖按钮；移动端显示右侧播放图标或长按菜单。
- “新建歌单”使用明确的虚线卡 / 加号卡，不与真实歌单混淆。

## E. 来源标签 `SourceTag`

| 类型 | 例子 | 语义 |
|---|---|---|
| Provider | 网易云、QQ音乐、更多平台 | 条目来源 |
| Local | 本地 | App 本地数据或本地媒体 |
| Mixed | 混合 | 一个本地歌单引用多 Provider 内容 |
| Quality | HQ、无损 | 当前播放 / 下载的质量信息 |

标签文本不得依赖颜色单独传达信息；颜色之外必须可读文字。

## F. 收藏控件 `FavoriteButton`

| 状态 | 图标 / 行为 |
|---|---|
| 已喜欢 | 实心红心；点击请求取消喜欢 |
| 未喜欢 | 描边心形；点击请求喜欢 |
| 只读来源 | 禁用心形；Tooltip / Sheet 说明“此来源无法写回收藏” |
| 多来源聚合 | 打开来源选择 Sheet，分别显示各来源状态 |
| 请求中 | 小型进度或禁用态，避免重复提交 |
| 请求失败 | 回滚原状态 + SnackBar + 可重试 |

## G. 搜索与筛选 `SearchAndFilterBar`

- 搜索输入默认提示：`搜索歌曲、歌手或专辑`。
- 筛选项可包括：来源、时长、标签、排序。
- 当前作用域必须清晰：例如“搜索：全部喜欢”或“搜索：网易云推荐”。
- 移动端筛选收纳到底部 Sheet，避免挤压 Tabs。

## H. 右侧播放栏 `NowPlayingPane`

桌面宽屏组件，包含：

1. 当前封面、歌曲名、歌手、来源与收藏状态。
2. 当前曲进度和核心播放控制。
3. 队列预览（默认 5 首）。
4. “来源 / 收藏状态”：当前播放来源、原始来源、收藏写回目标。

右栏不是另一个完整播放器；完整队列与歌词可从按钮进入抽屉或单独页面。

## I. 底部播放条 `DesktopPlayerBar`

- 固定在 Desktop Shell 底部，高度 76 px，**横跨整个窗口**。
- 左：封面 + 当前歌曲；中：播放控制 + 进度；右：音量 + 队列入口。
- 窗口变窄时优先保留暂停/下一首/进度；音量、重复、部分文字可折叠。
- 点击当前歌曲或封面打开完整播放详情。

## J. 移动迷你播放器 `MobileMiniPlayer`

- 高度 64 px，仅在有播放上下文时出现。
- 显示封面、歌名/歌手、暂停/播放、队列入口。
- 点击主体进入全屏播放器；按钮区域不触发页面跳转。
- 与 Bottom Navigation 之间有细分割线或阴影。

## K. 反馈组件

| 场景 | 组件 |
|---|---|
| 初次加载 | Skeleton（歌曲行 / 歌单卡 / 推荐模块） |
| 刷新 | 顶部线性进度或下拉刷新 |
| 空数据 | 空态插画 + 明确下一步 |
| 收藏/下载成功 | 简短 SnackBar，可撤销时带操作按钮 |
| 登录失效 | Inline Banner + “重新登录”按钮 |
| Provider 局部失败 | 来源级 Error Card，不阻塞其他来源 |

## L. 可访问性

- 点击区域最小 44 × 44 px。
- 所有图标按钮提供语义标签：播放、暂停、喜欢、更多、打开队列等。
- 不仅靠颜色表达来源、已喜欢或错误状态。
- 键盘：Tab 聚焦、Enter 播放、Space 暂停/播放、方向键在队列中移动。
- 文本缩放至 130% 时不截断核心操作；必要时换行或收纳次要列。
