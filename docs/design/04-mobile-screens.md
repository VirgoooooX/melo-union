# 04 · Android 页面规格

## 1. 移动端导航

移动端不复制桌面侧栏。建议使用五项 Bottom Navigation：

```text
喜欢 / 歌单 / 推荐 / 搜索 / 我的
```

- “下载”和“设置”收纳在“我的”。
- 播放时，Mini Player 固定显示在 Bottom Navigation 上方。
- 全屏播放器独立路由呈现；返回后保留原页面滚动位置和 Provider Tab。

## 2. 通用页面结构

```text
App Bar：小标题、搜索、溢出菜单
Provider Tabs：横向滚动
内容区：列表 / 卡片 / 推荐模块
Mini Player：有播放上下文时出现
Bottom Navigation
```

内容区不展示大型重复标题；例如“喜欢”页不再在 Tabs 下再次出现“喜欢”大标题。

## 3. 喜欢页

### Tabs

```text
[全部喜欢] [网易云] [QQ音乐] [更多]
```

### 内容

- 顶部紧凑操作行：`播放全部（128 首）`、排序/筛选按钮。
- 歌曲列表：封面 48 px，歌曲名 + 歌手 + 来源标签 + 时长 + 心形 + 更多。
- “全部喜欢”的多来源歌曲默认显示合并来源标签；点击心形进入 Bottom Sheet 选择具体来源。
- 下拉刷新时仅刷新 eligible Provider；局部失败显示来源状态 Banner。

## 4. 歌单页

### Tabs

```text
[本地歌单] [网易云] [QQ音乐] [更多]
```

### 内容

- 默认列表样式，卡片视图可作为切换项。
- 每行显示封面、名称、歌曲数、来源/混合标签、播放按钮与更多菜单。
- “新建歌单”放在页面顶部的轻量按钮或第一个卡片，不使用悬浮按钮遮挡 Mini Player。
- 本地歌单详情支持长按排序和移除条目；远端歌单按能力决定是否显示编辑。

## 5. 推荐页

### Tabs

```text
[网易云] [QQ音乐] [更多]
```

### 内容

- 卡片轮播或横向列表：每日推荐、风格精选、最近适合你。
- 下面是推荐歌曲列表和“播放全部”。
- 切换 Tab 时整页推荐内容从对应 Provider 刷新；禁止混合不同 Provider 的算法说明。
- 收藏、加入本地歌单、下载等菜单操作绑定条目的原始来源。

## 6. 搜索页

- 全局搜索入口，但结果按 Provider 分组或可用来源筛选。
- 默认显示最近搜索与热词；不在未配置来源时假装有结果。
- 搜索结果行显示来源标签、播放状态和收藏能力。

## 7. 我的页

建议分组：

```text
账号与来源
├─ 网易云 / QQ音乐 / 未来 Provider 的登录与状态

本地与下载
├─ 下载管理
├─ 本地媒体

应用设置
├─ 播放
├─ 外观
└─ 关于
```

## 8. Mini Player

- 高度 64 px。
- 左侧封面 44 px；中间两行文本；右侧暂停/播放与队列按钮。
- 手势：点击主体进入全屏播放器；向上轻扫可展开；点击按钮不触发打开。
- 当播放异常或 URL 失效时，Mini Player 显示弱错误状态和“重试”入口，不要静默停在暂停图标。

## 9. 全屏播放器

```text
顶部：收起 / 歌曲-歌词切换 / 分享
中部：大封面
信息：歌名、歌手、来源、质量、收藏
控制：进度、随机、上一首、播放、下一首、循环
底部：队列、歌词、喜欢、更多
```

- 当前播放来源与收藏写回目标可能不同；来源区应允许查看详情，避免误解。
- 触摸目标均不小于 44 × 44 px。
- 深色沉浸播放器允许作为局部主题，但与应用浅色页面之间应通过过渡和语义清楚区分。

## 10. 移动端适配注意点

- Tabs 超宽时横向滚动，禁止压缩成不可读文字。
- Provider 数量增长后，“更多”用底部 Sheet 列表承载。
- 多来源状态、长歌名、动态字体 130% 必须保持可用；省略优先级：专辑 > 次级来源标签 > 时间。
- 安卓返回键优先关闭 Sheet / 队列 / 搜索，再返回页面；播放器常驻状态不得丢失。
