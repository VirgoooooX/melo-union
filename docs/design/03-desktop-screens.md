# 03 · Windows 页面规格

## 通用 Shell

所有主页面共享同一套 Shell：

```text
DesktopPrimarySidebar | ProviderTabs + 页面内容 | NowPlayingPane
────────────────────────────────────────────────────────────────
DesktopPlayerBar（全宽）
```

- Shell 背景为 `canvas`；侧栏、内容区、右栏和播放条为 `surface`。
- 内容区上方直接从 Provider Tabs 开始，**不重复展示“喜欢 / 歌单 / 推荐”大型标题**。
- 右栏在宽度 ≥ 1280 px 固定；960–1279 px 可收起；< 960 px 进入紧凑模式。

## 1. 喜欢

### 默认：全部喜欢

```text
[全部喜欢] [网易云] [QQ音乐] [更多平台 ▾]

共 1,287 首歌曲                         [搜索] [来源] [排序]
# | 歌曲 | 歌手 | 专辑 | 来源 | 时长 | 添加时间 | 收藏 | 更多
```

### 内容规则

- “全部喜欢”合并所有 eligible Provider；同曲聚合为一行时，来源列展示多个 `SourceTag`。
- 歌曲行默认支持排序：最近添加、歌曲名、歌手、时长、来源。
- 右栏“来源 / 收藏状态”清楚标识：原始来源、当前播放来源、可写回的收藏目标。
- 多来源歌曲的心形点击弹出来源选择面板；单来源则直接切换。

### 单 Provider Tab

- 内容换为该 Provider 原始喜欢列表；保留搜索、排序和来源信息。
- 如果 Provider 登录失效，Tabs 仍可见，内容区显示登录 Banner 与缓存快照时间。

## 2. 歌单

### 默认：本地歌单

```text
[本地歌单] [网易云] [QQ音乐] [更多平台 ▾]

[搜索歌单] [视图：卡片/列表] [排序]

歌单卡网格
┌────────┐  ┌────────┐  ┌────────┐
│ 通勤   │  │ 睡前   │  │ 精选   │
│ 128 首 │  │ 86 首  │  │ 152 首 │
│ 混合   │  │ 本地   │  │ 网易云 │
└────────┘  └────────┘  └────────┘
```

### 内容规则

- 本地歌单可混合 Provider 引用；显示“混合”标签不代表歌曲已经下载。
- 支持卡片 / 列表两种视图；列表视图显示名称、歌曲数、来源、更新时间和更多菜单。
- “新建歌单”始终位于可见区域，使用加号卡或主按钮。
- 远端 Tab 仅展示该 Provider 可读取的歌单；编辑能力必须按 Provider capabilities 降级。

### 歌单详情

- 顶部显示封面、名称、歌曲数、来源和操作。
- 本地歌单支持拖拽排序、移除条目、添加备注。
- 对远端歌单，不能写回时隐藏编辑动作或显示只读提示。

## 3. 推荐

### 默认：首个可用推荐来源

```text
[网易云] [QQ音乐] [更多平台 ▾]

每日推荐                    [刷新] [更多]
┌卡片┐ ┌卡片┐ ┌卡片┐

最近适合你                  [播放全部]
歌曲列表

相似风格                    今日精选
```

### 内容规则

- 每个 Tab 对应一个 Provider；推荐模块与文案来自该 Provider，不进行跨 Provider 伪合并。
- 模块可包括：每日推荐、最近适合你、相似风格、编辑精选。
- 歌曲行的收藏目标就是当前推荐条目的来源 Provider。
- 右栏显示当前推荐来源、更新时间、推荐类型与连接状态。

## 4. 下载

- 左侧一级导航进入；不使用 Provider Tabs 作为默认结构。
- 按“下载中 / 已完成 / 失败 / 本地文件”分段。
- 单个任务显示来源、质量、进度、剩余时间、暂停/恢复/取消。
- Provider 无下载能力时，歌曲菜单只显示明确禁用原因，不显示无效下载入口。

## 5. 设置

- Provider 管理：登录、登出、启用/禁用、能力说明、上次同步状态。
- 播放设置：默认音质、播放行为、媒体键。
- 下载设置：默认目录、文件命名、并发与移动网络策略。
- 外观：浅色默认；深色主题作为后续完整 Variant，不在半成品状态混用。

## 6. 交互优先级

| 操作 | 行为 |
|---|---|
| 单击歌曲行 | 播放并以当前列表建立队列 |
| 单击来源标签 | 打开来源详情 / 切换到对应单来源视图 |
| 单击心形 | 修改该来源喜欢状态；多来源时先选择来源 |
| 单击播放条封面/名称 | 打开完整播放详情 / 右栏聚焦 |
| 单击队列入口 | 展开完整队列抽屉 |
| 切换 Provider Tab | 保持页面类型与筛选上下文，刷新该来源数据 |
